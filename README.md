# Guess_The_Number_Wiki_
This Repository is a wiki website for my game Guess The Number. 
This website started as a project in school in my trade and the first version ready to be published was finished in January 2025.
<br><br>

Easy Gamemode for GTN (Guess The Number) has already been released onto the <a href=“asep3192.com/Easy”>website,</a> itch io, and GTN - Easy is now on winget. <br>
Release date of GTN - Easy: (Publicy available) March 17, 2025.
<br><br>
Current version and difficulty released for GTN: Easy difficulty, version number 1.2.1 <br><br>
GTN is no longer available to download from Github and can only be downloaded from one of the following options: <br> <a href="https://asep3192.com/Easy">The GTN website, <a href="https://asep1582.itch.io/guess-the number"> itch io,</a> through the <a href="https://asep1582.itch.io/gtn-easy-set-up-installer">set up installer, </a>or through winget.</a> <br> You can install GTN Easy on winget using the following command. ```winget install Asep1582.GTN-Easymode```

<br><br>
The set-up installer for GTN - Easy was also recently released and can be downloaded from the easy page of GTN’s website or itch io.
